## Design lane

**Bold & expressive, brand/portfolio** — strong typography, high contrast, personality-forward. This is a personal portfolio, not a SaaS product. Opinionated choices are intentional.

## Typography

**Font stack**: Geist Sans (headings + body) + Geist Mono (code, labels, monospace accents). Both are loaded via the `geist` npm package and applied via CSS variables `--font-geist-sans` and `--font-geist-mono`.

### Scale (approximate, follow Tailwind class conventions)

| Role | Size | Weight | Notes |
|---|---|---|---|
| Display / Hero | `text-5xl` – `text-7xl` | 700–800 | Tight letter-spacing (`-0.04em`) |
| Page title (h1) | `text-4xl` | 700 | `-0.025em` |
| Section heading (h2) | `text-2xl` – `text-3xl` | 600–700 | |
| Sub-heading (h3) | `text-xl` | 500–600 | |
| Body | `text-base` (`16px`) | 400 | `leading-relaxed` |
| Caption / label | `text-sm` | 400–500 | Often `text-gray-500` dark mode `text-gray-400` |
| Mono / code label | `text-xs` – `text-sm` | 400 | `font-mono tracking-wide uppercase` |

### Rules
- Never use `font-italic` on headings for emphasis — use weight contrast instead.
- Mono labels (e.g., "For AI Systems") use `font-mono tracking-wide uppercase text-sm` as a "kicker" above section headings.
- Headings are `text-gray-900 dark:text-white`. Never mid-gray headings.

## Color system

**Mode**: Dark/light class-based via `next-themes`. The `dark` class is applied to `<html>`. Components use `dark:` Tailwind variants — NOT CSS variable swaps.

### Core palette

| Token | Light | Dark | Usage |
|---|---|---|---|
| Background | `bg-white` (#ffffff) | `bg-black` (#000000) | Page background |
| Surface | `bg-gray-100` | `bg-gray-900/50` | Cards, panels |
| Border | `border-gray-200` | `border-gray-800` | Dividers, card outlines |
| Text primary | `text-gray-900` | `text-white` | Headings, strong content |
| Text secondary | `text-gray-700` | `text-gray-300` | Body text |
| Text muted | `text-gray-500` | `text-gray-400` | Captions, metadata |
| Accent primary | `bg-blue-600` | `bg-blue-700` | CTAs, active states |
| Accent hover | `bg-blue-700` | `bg-blue-600` | CTA hover |
| Accent text | `text-blue-600` | `text-blue-400` | Links, inline highlights |

### Accent usage rules
- **Blue is the one accent**. Do not introduce purple, green, or orange for UI chrome.
- The `bg-blue-500/20` / `bg-blue-500/10` blob backgrounds are permitted as subtle ambient background elements only — never as a card background or section fill.
- Competition win labels or "champion" badges may use `text-amber-500` / `text-yellow-400` sparingly, only for literal award indicators.

### Prohibited color uses
- ❌ Full-bleed gradient backgrounds (`bg-gradient-to-br from-blue-500 to-purple-600`)
- ❌ `bg-indigo-*` or `bg-violet-*` as primary surfaces
- ❌ Semi-transparent colored card backgrounds (e.g., `bg-blue-900/30`) as primary surfaces
- ❌ Mid-gray headings (`text-gray-600` or lighter for h1/h2)

## Spacing & layout

### Grid
- Main content: `max-w-4xl mx-auto` (sections), `max-w-2xl` (prose/text columns)
- Desktop sidebar nav: fixed `w-64` left; content offset: `md:ml-64`
- Mobile: full width, floating bottom nav, `pb-20` content padding

### Spacing rhythm
- Section vertical padding: `py-16` – `py-24` (never less than `py-12` between major sections)
- Card internal padding: `px-6 py-6` standard; `px-4 py-4` compact
- Gap between card grids: `gap-4` – `gap-6`
- **Do not cram**. White space communicates confidence. When in doubt, add more vertical breathing room.

### Responsive breakpoints
- Mobile-first. `md:` = 768px (sidebar appears, bottom nav hides).
- Critical: `md:ml-64` offset on all non-full-screen pages. Full-screen pages (`/bizcomp`, `/meetup`, `/zakat-*`) have no offset.

## Component conventions

### Buttons / CTAs
```
Primary CTA:
  bg-blue-600 hover:bg-blue-700 dark:bg-blue-700 dark:hover:bg-blue-600
  text-white font-semibold rounded-lg px-6 py-3
  transition-all duration-300 hover:scale-105

Ghost / secondary:
  border border-gray-300 dark:border-gray-700
  text-gray-700 dark:text-gray-300
  hover:bg-gray-100 dark:hover:bg-gray-800
  rounded-lg px-6 py-3

Inline link:
  text-blue-600 dark:text-blue-400 hover:underline
```

**CTA text rules**: Always action-specific. Never "Learn More" / "Explore" / "Get Started".
- ✅ "View StockSimulatorBD", "See all competitions", "Read the case study"
- ❌ "Learn More", "Click here", "Explore my work"

### Cards
```
Standard card:
  bg-white dark:bg-gray-900/50
  border border-gray-200 dark:border-gray-800
  rounded-xl p-6
  transition hover:shadow-md

No card nesting. Cards do not live inside other cards.
```

### Badges / tags
- Use sparingly — only when the label carries meaningful information.
- Format: `text-xs font-medium px-2 py-0.5 rounded-full`
- For tech tags: `bg-gray-100 dark:bg-gray-800 text-gray-600 dark:text-gray-400`
- For award badges: `bg-amber-50 dark:bg-amber-900/20 text-amber-700 dark:text-amber-400 border border-amber-200 dark:border-amber-800`
- **Not every item needs a badge**. Use prose labels for metadata unless scanning benefit is clear.

### Navigation
- Sidebar (desktop): fixed left `w-64`, `bg-white dark:bg-black`, `border-r border-gray-200 dark:border-gray-800`
- Bottom nav (mobile): floating glass-pill `glass-effect bg-white/80 dark:bg-black/80 backdrop-blur`
- Active state: `text-blue-600 dark:text-blue-400 font-medium`

### Section headers
```
Kicker (above heading):
  text-sm font-mono tracking-wide uppercase text-gray-500 dark:text-gray-400 mb-2

Section heading:
  text-2xl md:text-3xl font-bold text-gray-900 dark:text-white mb-4

Section subtext:
  text-gray-700 dark:text-gray-300 max-w-2xl
```

## Animation

- **Blob background**: `animate-blob` keyframe (7s, infinite). Used only as a fixed background layer, `z-0`, never overlapping content. `will-change-transform` is applied.
- **Fade in**: `animate-fade-in-down` (0.5s ease-out) for above-the-fold hero elements.
- **Hover scale**: `hover:scale-105 transition-transform duration-300` for interactive cards/CTAs.
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` globally cuts all animations to `0.01ms`. Do not override this.

### Rules
- No auto-playing marquees/carousels by default.
- No parallax unless specifically requested.
- Animation delay helpers: `.animation-delay-2000` (2s), `.animation-delay-4000` (4s).

## Key anti-patterns (detected by Impeccable rules)

| Pattern | Why it's banned | Fix |
|---|---|---|
| `bg-gradient-to-* from-blue-* to-purple-*` full-bleed | Generic AI gradient slop | Remove; use flat surfaces or blob accents |
| Cards inside cards | Visual confusion, poor hierarchy | Flatten; use dividers or typography instead |
| `rounded-full` badges on every label | Badge soup | Use prose or a single meaningful badge per item |
| Vague CTAs | Doesn't tell user what happens | Rewrite with specific action + noun |
| `italic` serif emphasis in headings | AI tells — "ship the *plan*" pattern | Use weight or color contrast instead |
| Status-chip soup | Multiple colored pills per item | Reduce to one or zero; use typography |
| Cramped padding | Feels unpolished, rushed | Add `py-4` minimum to all inner containers |
| Everything equal visual weight | No hierarchy | Establish one hero, one secondary, rest subordinate |
