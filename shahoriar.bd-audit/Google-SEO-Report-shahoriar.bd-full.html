1. Executive Summary

This report presents a comprehensive SEO audit of shahoriar.bd for a Personal Portfolio & Professional Knowledge Hub site, generated on October 03, 2026. Findings combine technical, content, schema, performance, visual, and search-readiness evidence as available.

2. Audit Categories

2.1 Technical SEO

Score: 88/100

What Works

  • HSTS max-age 31536000 with includeSubDomains enabled
  • Strict security headers: X-Content-Type-Options, X-Frame-Options DENY, CSP frame-ancestors none
  • HTTP/3 and Cloudflare edge CDN acceleration with verified 200 responses
  • Dual HTTP Link header serving llms.txt and llms-full.txt discovery on all responses
  • 301 permanent redirect properly configured from /llm.txt to /llms.txt

Findings

Homepage Canonical Trailing Slash Mismatch with Sitemap Medium

app/page.tsx declares alternates.canonical as 'https://shahoriar.bd/', whereas app/sitemap.ts emits 'https://shahoriar.bd' without trailing slash. This discrepancy causes search engines to evaluate two canonical candidates.

Recommendation: Remove the trailing slash in app/page.tsx to match sitemap.xml ('https://shahoriar.bd').

Missing Canonical Tag on /techtips and /ide Medium

app/techtips/layout.tsx and app/ide/page.tsx do not declare an alternates.canonical URL, leaving query strings or trailing slashes vulnerable to duplicate indexing.

Recommendation: Add alternates: { canonical: 'https://shahoriar.bd/techtips' } to app/techtips/layout.tsx and alternates: { canonical: 'https://shahoriar.bd/ide' } to app/ide/page.tsx (or mark /ide with robots noindex if private).

Crawl Isolation Gaps for Standalone Routes in robots.txt Low

Internal and private apps (/shoily, /bizcomp, /meetup) are excluded from the sitemap but not disallowed in robots.txt. /meetup also contains an unencoded replacement character in its title.

Recommendation: Add Disallow rules in app/robots.ts for /shoily, /bizcomp, and /meetup, or ensure they explicitly carry robots: { index: false }.

2.2 Content Quality & E-E-A-T

Score: 92/100

What Works

  • Firsthand expertise and institutional affiliations (EY Bangladesh, bKash, ICAB, BUP)
  • Zero filler content, zero detected AI generic pattern phrasing (overall quality score: 91/100)
  • External authority backlinks and citations to official BUP news and business press
  • Detailed statutory compliance architecture for Bangladesh Youth Tax Calculator

Findings

Duplicate H1 Tags on Blog Detail Pages High

In app/life/[slug]/page.tsx, the article title renders as an <h1>, but the Contentful rich text renderer also maps BLOCKS.HEADING_1 to an <h1>. Any post containing a top-level heading in Contentful has multiple <h1> elements.

Recommendation: Change BLOCKS.HEADING_1 in the rich text renderNode to render an <h2>, BLOCKS.HEADING_2 to <h3>, and BLOCKS.HEADING_3 to <h4>.

Homepage H1 Text Concatenation Medium

In app/components/HeroSection.tsx, the <h1> includes both an sr-only span with the full name and visual block spans with the name split. Search engines concatenate these into 'Md Al Shahoriar HossainMD ALSHAHORIARHossain'.

Recommendation: Provide visual text within standard spans and avoid duplicating the entire name in an adjacent sr-only container inside the same <h1>.

Heading Level Skips on /projects and /design-portfolio Medium

app/projects/ProjectsContent.tsx skips from <h1> directly to <h3> without any intermediate <h2>. /design-portfolio lacks an <h1> element entirely, starting at <h2>.

Recommendation: Add section <h2> headings on /projects and add an <h1> page header on /design-portfolio.

2.3 On-Page SEO

Score: 82/100

What Works

  • Unique titles and descriptive meta descriptions across core portfolio sections
  • Targeted keywords mapped to specific projects (Youth Tax Calculator, Tapo-Viewer, LocReminder)
  • Clear hierarchy and semantic sectioning across desktop and mobile shells

Findings

Missing Page-Level Open Graph and Twitter Metadata on 7 Key Routes High

/skills, /education, /projects, /life, /ai, /contact, and /design-portfolio do not define openGraph or twitter card metadata. When shared on social platforms, they fallback to generic homepage text.

Recommendation: Export specific openGraph and twitter objects in the metadata of each page with customized titles, descriptions, and canonical URLs.

Buried Resume & Recruiter Friction (SXO) Medium

The primary conversion goal for a professional portfolio is employer and recruiter evaluation. The resume (/resume.md) is buried under the bottom AI profile section rather than in the primary navigation or Hero CTA.

Recommendation: Add a direct 'Resume' link in app/components/nav.tsx and a secondary CTA button in HeroSection.

2.4 Schema / Structured Data

Score: 88/100

What Works

  • Comprehensive Person schema linked with @id: https://shahoriar.bd/#person
  • Valid WebSite schema referencing the Person entity as publisher
  • Rich SoftwareApplication schema on project subpages and BreadcrumbList markup on secondary pages
  • BlogPosting schema on /life/[slug] with publishedTime, modifiedTime, and author

Findings

Missing ContactPage and Credential Structured Data Low

/contact lacks ContactPage / ContactPoint schema. /skills certifications tab does not provide EducationalOccupationalCredential or ItemList schema.

Recommendation: Inject ContactPage schema on /contact and ItemList / EducationalOccupationalCredential markup on /skills.

Deprecated FAQPage SERP Feature Advisory Info

Google retired FAQ rich result accordions for all sites on May 7, 2026. Existing FAQPage markup on homepage and /projects/youth-tax-calculator provides no SERP accordion benefits.

Recommendation: Retain existing FAQ schema for AI entity understanding, but do not rely on it for Google SERP snippet expansion.

2.5 Performance (CWV)

Score: 90/100

What Works

  • GeistSans and GeistMono zero-layout-shift font configuration
  • Deferred third-party tracking (Microsoft Clarity initializes on requestIdleCallback / 3s timeout)
  • Priority loading on desktop hero portrait and responsive next/image optimization
  • Clean mobile viewport (no horizontal scroll, touch targets verified)

Findings

Absence of Speculation Rules and fetchpriority="high" Medium

preload_check.py scored 50/100. While Next.js provides client router prefetching, adding Speculation Rules API enables instant prerendering for top user pathways (/skills, /projects, /ai).

Recommendation: Add a <script type="speculationrules"> block in layout.tsx or next.config.js headers, and ensure hero images carry fetchpriority="high".

2.6 AI Search Readiness

Score: 86/100

What Works

  • Dedicated /ai machine-readable profile with extensive factual data and verification date
  • Permanent llms.txt and llms-full.txt links advertised via HTTP Link headers
  • 100/100 score on agent_ux_check.py (semantic landmarks, accessible controls, zero div-onclick widgets)
  • Open robots policy allowing all major AI search crawlers (GPTBot, Claude-SearchBot, PerplexityBot, Applebot)

Findings

llms.txt Fails Official Specification & Lighthouse Agentic Audit High

agentic_check.py flagged llms.txt as failing Lighthouse Agentic criteria: missing blockquote summary ('> ...') and using bare text URLs instead of Markdown formatted links [Name](url).

Recommendation: Rewrite app/llms.txt/route.ts to include a blockquote summary below the title and format all links as markdown links with concise descriptions.

2.7 Images

Score: 80/100

What Works

  • WebP/AVIF automated image generation via next/image
  • Explicit width/height or fill containers preventing cumulative layout shifts (CLS)

Findings

40+ App Logos with Empty alt="" on /techtips Medium

ItemCard in app/techtips/page.tsx renders images with alt="", treating all software and tool logos as decorative images.

Recommendation: Update ItemCard to use alt={`${item.name} logo`} for accessible identification and image search indexing.

External Free Image Hosting (i.ibb.co.com) Medium

EY company logo on /skills and Tapo-Viewer screenshots load from i.ibb.co.com, introducing third-party DNS latency and link expiration risk.

Recommendation: Download and host all images locally in public/skills/ and public/projects/tapo-viewer/.
